# Claims register

Every capability that the README or the site states about this repository is
listed here with what implements it, the check that proves it, and its status.
Statuses: `shipped` (implemented, and the check passes in CI), `local` (implemented,
the check passes locally, CI has not run it on GitHub), `roadmap` (not implemented).
`shipped` rows were first proved by CI run
https://github.com/matteogallo-ai/site/actions/runs/42036373324 (PR #1); the measures and
demo-trace rows by https://github.com/matteogallo-ai/site/actions/runs/42041962003 (PR #2); the home
page rows by https://github.com/matteogallo-ai/site/actions/runs/42056375408 (PR #3), and the
magnifier and answer-writing rows as worded now by https://github.com/matteogallo-ai/site/actions/runs/42063330369 (PR #4); the spotlight, first-screen, translation-source, tooltip and placeholder rows by https://github.com/matteogallo-ai/site/actions/runs/42078669445 (PR #9); the case-study rows by https://github.com/matteogallo-ai/site/actions/runs/42090811849 (PR #11, which replaced #8); the Colophon, 404, link-preview and sitemap rows by https://github.com/matteogallo-ai/site/actions/runs/42098170558 (PR #12); the English-version rows (EN shipped, hreflang, selector, no French on English pages, English link preview, English 404) by https://github.com/matteogallo-ai/site/actions/runs/42200596761 (PR #13); the production-origin row by https://github.com/matteogallo-ai/site/actions/runs/42216523816 (`main` at fcada55); the review-pass rows (inline code to icons) by https://github.com/matteogallo-ai/site/actions/runs/42239261142 (PR #15).
